## Getting started

```bash
git clone https://github.com/Azealoo/hackathon-2026-credit-rec.git
cd hackathon-2026-credit-rec
```

## Workflow

- Branch off `main` for each feature: `git checkout -b feature/<short-name>`
- Open a pull request into `main` and ask a teammate to review
- Never commit secrets (API keys, `.env` files)
